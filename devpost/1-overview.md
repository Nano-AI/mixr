# Project overview

## Project name

mixr

## Elevator pitch

An entire social network in your messages.

Alternates:

- A social network that lives in your texts.
- Turns "we should hang out" into Thursday at 5.
- Stop saying "we should hang out."
- Text what you're into. Show up Thursday.
- Text a vibe, get a plan.
- You text it. It texts back a plan and the people.
